Privacy statement.

Dallas stores app data with Supabase in Europe and is built to follow GDPR guidelines. This page explains the data used by the current first draft, version 1, build 12.

Hosting and GDPR

Dallas app data is hosted by Supabase in Europe. We follow GDPR guidelines for privacy, access control, and deletion of user data. Supabase authentication is used for account creation, sign in, signup confirmation, and password recovery.

The database uses row-level security so signed-in users can manage their own records. Some profile basics may be visible to connected Dallas accountability buddies so the buddy feature can work.

Deleting your account

If you delete your Dallas account in the app, your Dallas app data is deleted and is not retrievable. This includes your profile, recovery plans, accountability information, event plans, reminders, images, audio files, push tokens, and stored app content connected to your account.

Deleting the app from your phone does not automatically delete the cloud account. Use the in-app account deletion option when you want the account and related Dallas data removed.

Database features

  • Supabase Auth for email accounts, signup confirmation, sessions, and password recovery.
  • Postgres tables for profiles, recovery plans, accountability, Prophetic Vision, and event plans.
  • Row-level security policies that scope records to the signed-in user or connected buddy relationship.
  • Storage buckets for avatars, home cover images, accountability avatars, vision covers, and vision audio.
  • Edge functions for check-in replies, account deletion, and server-side assistant features.
  • Push-token storage for notification and reminder support.

Data collected

  • Account details: email address, user ID, display name, phone number, and profile settings.
  • Profile media: avatar paths and home cover image paths.
  • Recovery content: plan titles, high-risk situations, vision text, coping steps, and support notes.
  • Accountability content: partner details, planned check-ins, notes, reply threads, and messages.
  • Dallas App Buddies: app buddy connections, message history, unread state, and connection status.
  • Prophetic Vision: short and long text, cover image paths, audio paths, and audio file names.
  • Event planning: event details, warnings, anchors, reminders, scripts, call plans, and debrief notes.
  • Notifications: push tokens, platform, scheduled reminder references, and last-seen timestamps.
  • Device-only settings: local OpenAI API key storage and legal acknowledgement state can live on the device.
